# Индексация

Обе HTML-страницы содержат robots noindex, nofollow, noarchive, nosnippet, noimageindex.
Файл _headers добавляет X-Robots-Tag на поддерживающем его хостинге.
robots.txt разрешает обход, чтобы поисковики могли прочитать noindex.
После публикации уже проиндексированные страницы исчезают по мере повторного обхода.
Не публиковать recovery-backup, RESTORATION.md и служебные скрипты.
